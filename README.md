# CIS7 Course Project

## Project Description
This project is a C++ program developed for the CIS 7 Discrete Structures course.  
The purpose of the program is to demonstrate how discrete structure concepts can be applied in programming, including logical decision-making, structured control flow, and algorithmic thinking. The program processes user input, applies defined rules and conditions, and produces an appropriate output based on those computations.

## Programming Approach
The program is written in C++ and follows a structured programming approach.  
Key concepts applied include:
- Conditional logic (if/else statements)
- Iterative control structures (loops)
- Clear input and output handling
- Algorithmic reasoning based on discrete structures concepts covered in class

The source code is organized in a single file for simplicity and clarity.
